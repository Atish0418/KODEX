# 📝 Inkwell - Blog Platform

Inkwell is a modern blog application built using React. It allows users to create, read, and manage blog posts with a clean and minimal UI.

---

## 🌐 Live Demo

👉 https://your-live-link.vercel.app

---

## 🚀 Features

* 📰 Create and publish blog articles
* 📖 Read full blog details
* 🏷️ Add tags to articles
* 💾 Data stored using LocalStorage
* 🔐 Authentication (Login / Register)
* 🔒 Protected routes for secure access
* ⚡ Fast and responsive UI

---

## 🛠️ Tech Stack

* Frontend: React.js
* Routing: React Router
* State Management: Context API
* Styling: Tailwind CSS
* Icons: Remix Icons

## ⚙️ Installation & Setup

```bash
git clone https://github.com/your-username/inkwell.git
cd inkwell
npm install
npm run dev
```

---

## 🧠 How It Works

* Users can create blog posts from the Create page
* Blogs are stored in LocalStorage
* Home page displays all articles
* Clicking a blog opens full details
* Protected routes ensure only logged-in users can create/edit blogs
